# Первый запуск на Mac — с нуля

Приложение открывается в браузере, а фотографии обрабатываются на вашем Mac.
В архиве уже есть готовая сборка. Для её запуска нужны Node.js и современный браузер.

## 1. Скачайте архив приложения

Нажмите **[Скачать HEIC-конвертер ZIP](https://github.com/zorok-vi/heic_converter/archive/refs/heads/main.zip)**.

Альтернативный путь: откройте https://github.com/zorok-vi/heic_converter,
нажмите зелёную кнопку **Code**, затем **Download ZIP**.

Архив `heic_converter-main.zip` появится в папке **Загрузки** вашего Mac.
Откройте Finder → Загрузки и дважды нажмите на архив. Если браузер уже распаковал
его автоматически, используйте появившуюся папку **heic_converter-main**.

Переместите папку **целиком** в **Документы**. Внутри должны быть папки `dist`
и `scripts`, файлы `start.command`, `start.sh`, `package.json` и остальные файлы проекта.

## 2. Установите Node.js

Откройте официальный сайт **https://nodejs.org/en/download**.
Выберите версию **24.x**, начиная с **24.15.0**, систему **macOS** и установщик **.pkg**.
Этот проект поддерживает ветку 24; версия 26 и старые версии 22 не входят в его диапазон.

Если сайт предлагает архитектуру, откройте ** → Об этом Mac**:

- чип Apple M1, M2, M3 и другие M-серии → **ARM64 / Apple Silicon**;
- процессор Intel → **x64 / Intel**.

Откройте скачанный `.pkg` и следуйте установщику: **Продолжить → Установить**.
Оставьте стандартное место установки. Установщик может запросить пароль учётной
записи macOS. После установки заново откройте Терминал, если он уже был запущен.

## 3. Проверьте Node.js

Нажмите **⌘ Command + Пробел**, напишите **Терминал**, нажмите Enter.
Введите следующую команду и нажмите Enter:

```sh
node --version
```

Должен появиться номер вида `v24.19.0`. Нужна версия не ниже `v24.15.0` в ветке `v24`.
Если написано `command not found`, закройте и заново откройте Терминал.
Если сообщение осталось, установка Node.js не завершилась.

## 4. Откройте папку приложения в Терминале

Напишите `cd` и поставьте после него один пробел. Пока не нажимайте Enter.

Перетащите папку **heic_converter-main** из Finder прямо в окно Терминала.
Её полный путь подставится автоматически. Теперь нажмите Enter.

Чтобы убедиться, что вы в нужной папке, выполните:

```sh
ls
```

В списке должны быть `start.command`, `start.sh`, `scripts` и `dist`.

## 5. Запустите приложение

Один раз после распаковки разрешите запуск скриптов:

```sh
chmod +x start.sh start.command setup.sh
```

Затем запустите приложение:

```sh
./start.command
```

В Терминале появится адрес **http://127.0.0.1:8080**. Браузер должен открыться
автоматически. Если этого не произошло, скопируйте адрес в адресную строку браузера.
Окно Терминала оставьте открытым во время работы приложения.

Для первого запуска рекомендуется Chrome или Edge. Chrome можно установить
с **https://www.google.com/chrome/**: открыть скачанный `.dmg`, перетащить Chrome
в **Программы / Applications** и открыть его оттуда. Если браузер по умолчанию другой,
вставьте локальный адрес в Chrome вручную. Safari пока не проверен.

## 6. Конвертируйте фотографии

Нажмите **Выбрать файлы**, выберите HEIC/HEIF, укажите JPEG или PNG и нажмите
**Конвертировать**. Затем скачайте отдельные результаты или **Скачать ZIP**.
Место сохранения определяют настройки браузера — обычно это **Загрузки**.
Оригиналы приложение не меняет. Результат иногда больше исходного файла.

## 7. Завершите работу и запустите снова

В окне Терминала нажмите **Control + C** — именно Control, а не Command.
Закрытие вкладки само по себе не останавливает локальный сервер.

Для следующего запуска можно дважды нажать на `start.command` в Finder.
Если macOS не позволяет открыть его таким способом, повторите запуск через
Терминал командой `./start.command`, как описано выше. Не отключайте защиту macOS.
При ошибке сохраните точный текст сообщения для диагностики.

## Если возникла ошибка

**«Permission denied».** Выполните `chmod +x start.sh start.command setup.sh` и повторите запуск.

**«No such file or directory».** Терминал открыт не в папке приложения.
Повторите шаг 4: `cd`, пробел, перетаскивание папки в Терминал, Enter.

**«Сборка dist отсутствует или повреждена».** Скачайте полный архив ещё раз.
Либо выполните однократную подготовку из исходников (для неё нужны интернет и npm):

```sh
./setup.sh
./start.command
```

**«Порт 8080 занят».** Запустите с другим портом:

```sh
./start.command --port 8081
```

Затем откройте **http://127.0.0.1:8081**.

**Node.js сообщает, что версия не поддерживается.** Установите Node.js **24.15+ в ветке 24**.

## Что проверено

Фактически проверены Linux + Chromium, настоящая HEIC-конвертация и работа
готовой сборки без node_modules. На настоящем Mac испытания пока не проводились.
Полный перечень проверок и ограничений — в [TEST_REPORT.md](TEST_REPORT.md).
Сохранение HDR/ICC и обработка предельных партий на любом Mac не гарантируются.
